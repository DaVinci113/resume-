# Описание

Серия личных проектов, направленных на изучение и применение AI/ML-технологий, работы с аудио-потоками и локальным развёртыванием LLM. Фокус на приватности, offline-работе и оптимизации ресурсов.

## Стек
- Python (основной язык)
- LLM / Local LLM (Qwen, локальное развёртывание)
- Vosk (offline Speech-to-Text)
- TTS (синтез речи)
- SoundDevice (захват аудио-потока)
- PostgreSQL (хранение контекста диалогов)
- Queue (потокобезопасная обработка аудио)
- uv (менеджер зависимостей)
- NumPy (обработка аудио-сигналов)

## Обязанности
- Проектирование архитектуры автономных AI-приложений
- Интеграция локальных LLM и offline-моделей распознавания речи
- Оптимизация потребления памяти и CPU для работы на десктопе
- Реализация state machine для управления состояниями ассистента

## Достижения
- Создал полностью offline голосовой ассистент с wake-word детекцией, распознаванием речи и синтезом ответа — без отправки данных в облако.
- Реализовал гибридный роутинг: простые команды выполняются мгновенно, сложные — через локальную LLM с озвучкой ответа.
- Добился устойчивой работы с фоновым шумом через partial-result распознавание Vosk.
