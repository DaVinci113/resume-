# Описание

## Описание проекта
-  Комплексная система для автоматизации рутины поставщиков маркетплейсов. Сервис в фоновом режиме собирает статистику продаж, отслеживает финансовые показатели, остатки товаров, отзывы покупателей, изменение медиа, агрегирует данные по товарам, брендам и магазинам и предоставляет пользователям доступ к аналитике через Web-интерфейс и Telegram-бота.

## Результаты
* **Архитектура и Backend (Django):** Спроектировал и разработал ядро системы на Django. Создал реляционную схему БД для управления пользователями, тарифами и предзаказами аналитических отчетов (модель `PreorderWork`).
* **Обработка данных (Celery + Redis):** 
  * Вынес тяжелые операции (парсинг API Wildberries, агрегация статистики, генерация Excel/PDF отчетов) в фоновые задачи с использованием **Celery**.
  * Настроил **Celery Beat** для периодического (cron-like) автоматического обновления статистики по всем активным селлерам.
  * Реализовал кастомный механизм трекинга статусов задач через поле `task_id` в базе данных, что позволило frontend-приложению и Telegram-боту отображать пользователям прогресс выполнения («Отчет формируется...», «Готово»).
* **Интеграция с Telegram:** Разработал полнофункционального Telegram-бота как альтернативный интерфейс взаимодействия. Реализовал меню команд, систему подписок, отправку дайджестов с настраиваемым периодом и автоматическую рассылку юридической оферты (`/offerta`).
* **Интеграция платежной системы**
  * Реализовал систему монетизации (4 тарифа, триальный период) и интегрировал платежный шлюз YooKassa, что обеспечило конверсию в платных пользователей.
* **DevOps и деплой (Docker):** 
  * Полностью контейнеризировал инфраструктуру. Написал `docker-compose.yml` для оркестрации 5 сервисов: Django App, Celery Worker, Celery Beat, Redis (как брокер сообщений) и PostgreSQL.
  * Настроил production-окружение с Nginx в качестве reverse-proxy.
  * Автоматизировал безопасность: написал bash-скрипт (`renew_certs.sh`) и интегрировал его с Certbot и системным cron, обеспечив автоматическое продление SSL-сертификатов Let's Encrypt без простоя сервиса (zero-downtime).
* **Оптимизация:** Внедрил обработку rate-limits API маркетплейсов и настроил автоматические повторные попытки (retries) для упавших Celery-тасок при временной недоступности внешних API.
