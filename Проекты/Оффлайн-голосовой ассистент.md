# Описание

## Описание проекта
Локальный голосовой ассистент (Desktop-приложения), работающего в фоновом режиме. Проект решает задачу создания приватного "умного помощника", который не отправляет голосовые данные в облако. Ассистент непрерывно слушает микрофон, активируется по заданным wake-словам (например, «Пелагея», «Жорик»), выполняет жестко заданные голосовые команды (открытие веб-сайтов) и, при нестандартных запросах, обращается к локально развернутой LLM (Qwen) для генерации осмысленного ответа с последующим его озвучиванием.

## Моя роль
- **Захват и потоковая обработка аудио:** Настройка непрерывного считывания аудиопотока с микрофона (`SoundDevice.RawInputStream`) и передача данных в `queue.Queue` для исключения блокировок основного потока.
- **Интеграция offline Speech-to-Text:** Внедрение библиотеки **Vosk** с использованием русской модели (`vosk-model-small-ru-0.22`) для распознавания речи с низкой задержкой.
- **Реализация State Machine (Машины состояний):** Проектирование архитектуры состояний ассистента: _ожидание wake-word_ ➔ _слушание команды_ ➔ _выполнение/генерация ответа_ ➔ _сброс по таймауту_.
- **Интеграция локальных нейросетей (LLM):** Подключение к локальному серверу для обработки диалоговых запросов, которые не попадают под базовые команды.
- **Обработка системных команд:** Создание маппинга голосовых команд на действия (открытие браузеров, YouTube, Roblox) через модуль `webbrowser` и кастомную конфигурацию.
- **Синтез речи (TTS):** Настройка озвучивания системных сообщений и ответов языковой модели.

## Результаты
- **Полная приватность:** Создан голосовой помощник, который работает без интернета, не передавая голос пользователя третьим лицам.
- **Гибридная архитектура принятия решений:** Реализован умный роутинг запросов: жестко заданные команды (открытие сайтов) выполняются мгновенно, а сложные вопросы перенаправляются в локальную LLM с последующей озвучкой ответа.
- **Устойчивость к фоновому шуму:** Внедрена система частичного распознавания (`PartialResult`), которая позволяет ассистенту реагировать на wake-слова еще до того, как пользователь закончит фразу, что значительно ускоряет отклик системы.
- **Настроена гибкая система триггеров:** Реализован надежный механизм обнаружения wake-слов в частичных (partial) и финальных результатах распознавания Vosk, что снизило время отклика ассистента.
- **Обеспечена отказоустойчивость:** Внедрены таймауты ожидания команд (10 сек.) и автоматические сбросы буфера (`recognizer.Reset()`), предотвращающие накопление "шумового" текста и ложные срабатывания.
